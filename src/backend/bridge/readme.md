# bridge

## node

核心目录: `backend/bridge/node/`
技术选型: `[ts, esbuild, pnpm, node]`
风格规约:
- 配置独立: 针对可以独立编写配置的工具, 要求配置尽可能采用特定的配置文件, 避免 package.json 大杂烩.
- 导入导出: 使用 esm 风格, 尽可能现代化同时考虑必要的兼容.
- 类型明确: 充分利用 ts 的类型系统标注类型.
- 命名风格: 驼峰式命名.
- 编码风格: 面向过程 > 面向对象, 尽可能避免出现面向对象编程; 模块化并考虑解耦.
- 注释信息: 代码清晰性 >> 注释; 只在关键的决策上加上注释.
- 工具使用: 优先 pnpm, 没有则回退 npm.
实现步骤:
- 在核心目录下创建服务处理骨架, 通过基础的esbuild->tsc->run链路.
